# Resolve-IQ

A professional complaint management system built with Python and SQLite, designed to efficiently track and manage customer feedback and complaints.

GitHub Repository: [https://github.com/12StoneDesigns/Resolve-IQ](https://github.com/12StoneDesigns/Resolve-IQ)

## Features

- User-friendly interface for submitting complaints
- Secure database storage using SQLite
- Real-time complaint tracking
- Gender-inclusive form design
- Comprehensive complaint listing and management
- Bulk actions support:
  - Select multiple complaints (using Click+Drag, Ctrl+Click, or Shift+Click)
  - Update status of multiple complaints at once
  - Delete resolved complaints in bulk
- Advanced filtering and search capabilities
- Status tracking (Pending, In Progress, Resolved, Closed)
- Priority levels (High, Medium, Low)

## Technical Stack

- Python 3.x
- SQLite3 Database
- Tkinter GUI Framework
- Matplotlib for analytics

## Dependencies

- sqlite3
- tkinter
- matplotlib

## Installation

1. Ensure Python 3.x is installed on your system
2. Clone the repository:
   ```bash
   git clone https://github.com/12StoneDesigns/Resolve-IQ.git
   ```
3. Run `python main.py` to start the application

## Usage

The system provides two main interfaces:

1. Complaint Submission Form - For entering new complaints
2. Complaint List Viewer - For managing complaints with features:
   - Multi-select support for bulk operations
   - Status updates (Pending, In Progress, Resolved, Closed)
   - Delete functionality for resolved complaints
   - Advanced search and filtering
   - Real-time updates

### Bulk Operations
- **Multiple Selection**: Use Click+Drag, Ctrl+Click, or Shift+Click to select multiple complaints
- **Status Updates**: Select multiple complaints and use the status dropdown to update them all at once
- **Delete Resolved**: Select complaints and use the "Delete Resolved" button to remove resolved complaints
